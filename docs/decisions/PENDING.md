# Decisions not yet written up

Commits that changed the server and shipped without a decision record. The
post-commit hook writes this list; nothing else does.

A row here is not an accusation — plenty of server commits are refactors, copy or
tests and owe nothing. It is a backlog: **a decision nobody wrote down is one
nobody can revisit.** Clear a row by writing the record (`./tools/decide.sh`) and
deleting the line.
