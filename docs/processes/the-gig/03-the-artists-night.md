# The artist's night (Studio → Live)

**Who:** the artist, or a team member with a role that allows running a show (role *Artist* / *Artist team member*, external), on their own phone, one-handed, in low light. **Trigger:** opening `/studio` on the night. **Outcome:** a show that started, played the room's choices, and ended — and was filed to the past-shows archive.

The Studio is dark-only by design. The Live tab polls `/api/stage` every 4 seconds.

| a07 | Start the top-voted song | task | Person | Artist R · MySet server R · Fan I | Netlify | `playTop`: the pool is what the room can vote for right now (`votable()`, one definition), minus the song playing, minus played songs unless they hold replay votes, minus anything with zero votes. Empty → **409 "nothing left in the pool"**. Within `DOUBLE_TAP_MS` of the last start → **409 "That one just started — give it a moment"** (a retry would pick the *next* song down, the worst outcome). **Past that window the tap id holds it (decision 0151):** the Studio sends an id with each Play tap and the same id with that tap's retry; the show keeps the last few in the write that starts the song, and an id it already holds is answered with the stage (`repeat: true`) and never obeyed twice. With no answer the Studio reads the stage before it lets another tap through. The tally is captured **before** it is wiped (`logPlay`), so the show log records what that song collected. `src: admin.mjs playTop; studio.js playAct; overview §1.16; INVARIANT 0hy` |

| a09 | Take the song's votes off the board | database | Automation | MySet server R · Fan I | Netlify | **The show write itself collects them (decision 0147).** Play and Play Top add one to `show.plays` and mark the song with the new count (`show.col`); every vote row carries the `plays` its cast had read, and a row stamped lower than its song's mark is left out wherever the board is drawn (`liveFans`: the room's board, the fan's own votes, the Studio's queue, Play Top's ranking). So a vote that set off before Play and lands after it is collected like the rest, instead of sitting on the song as a cheap request to hear it again. ## Things the artist cannot do (deliberately)

- Refund on play, hide, delete, clear or end (decision 0001). Only a15 refunds.
- Turn *Last call* into a lock — there is a separate switch for that (a11).
- Make the room bigger mid-set by upgrading — the size is stamped at start (a06).
- Start a show past the free plan's cap of shows in total (a04) — the only thing the free plan refuses; every room-facing feature stays free on every plan (VISION rule 3).
