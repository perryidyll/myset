# The automation engine

**Who:** an agent session (the creator-analyst panel) and the founder at the gate. **Trigger:** daily for ingest; weekly for everything else. **Outcome:** eight stages in a loop — ingest, analyse, generate, **human gate**, produce, publish, measure, learn — where stages 1, 2, 3, 7 and 8 automate well, 5 and 6 partly, and **stage 4 is never removed**. The engine produces briefs, not scripts, and the gate is what keeps it from producing confident nonsense. Built as an extension of the multi-agent content-intelligence roster the founder already has, not from scratch.

All **Draft** — nothing is wired; the roster exists as prompts, the database does not exist yet. The agent steps are attributed to the *Coding agent* role because the workspace has no content-agent role (see the session record).
